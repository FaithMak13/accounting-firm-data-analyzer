# Accounting Firm Data Analyzer

## Project Description
The Accounting Firm Data Analyzer is a Python program created to analyze employee information for a fictional accounting firm with 40 employees.

The firm has four departments:
- Secretarial
- Accounting
- Trusts & Estates
- Audit & Clerks

The program reads employee information from a CSV file and calculates useful statistics about salaries, departments, length of service, and training.

## Questions the Program Answers

1. Which department has the most employees?
2. Which department has the highest average monthly salary?
3. What is the firm's total monthly payroll?
4. What is the average monthly salary?
5. Which employee has the highest monthly salary?
6. Which employee has the lowest monthly salary?
7. How many employees have completed at least two training courses?

## Features

- Reads data from a CSV file using pandas.
- Calculates salary statistics.
- Groups employees by department.
- Calculates departmental payroll and average salary.
- Identifies the highest-paid employee.
- Counts employees by department.
- Creates charts showing salary and employee distribution.
- Uses functions to keep the program organized.

## Files

- `accounting_data_analysis.py` - Main Python program.
- `employees.csv` - Employee dataset.
- `README.md` - Project documentation.
- `requirements.txt` - Python libraries required.

## How to Run

1. Install Python 3.
2. Open a terminal in this project folder.
3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run:

```bash
python accounting_data_analysis.py
```
